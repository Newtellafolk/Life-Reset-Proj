# Anonymous-first account model

Life Reset targets people who are already afraid to be judged and hesitant to ask anyone for help; a signup wall on first open would reinforce exactly that fear before the product has earned any trust. We decided a user can start a full Session — text or voice, problem capture, prioritization, Action Steps — with no account at all, and is only invited to sign up later, at a moment where the value is already obvious (nearing the monthly Usage quota, or wanting History to survive across devices/reinstalls). We considered requiring signup upfront, which would have made Usage-quota enforcement and cross-device History trivial from day one, but rejected it because the trust cost outweighs that engineering convenience. This constraint should be treated as a product boundary, not a growth-metric default to "fix" later by moving signup earlier in the funnel.
