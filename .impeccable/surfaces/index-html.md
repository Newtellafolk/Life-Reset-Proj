## Direction contract

THESIS: Life Reset treats every overlapping problem as a real sticky note on a corkboard the user's own hands control — refusing both the generic chatbot Q&A log and the pastel-wellness-app gradient that would hide the "sort your mess into order" mechanic behind chrome instead of showing it.

OWN-WORLD: Warm kraft-paper and cork-board ground (#C9A66B / #F3EAD8), one coral pushpin accent (#D97B5F) marking today's top priority, chalk-slate ink (#3A3530) for all text; sticky-note cards with soft lifted-paper shadows and brass-pushpin iconography, plain-spoken status labels, no gradients, no blob mascots.

STORY: The user opens to a corkboard already holding their raised Problems as sticky notes; the Companion has proposed an order via a highlighted pushpin, and the user trusts their own hands to rearrange it — drag notes, tap one to enter grounding conversation, watch resolved notes dissolve softly off the board.

FIRST VIEWPORT: Mobile portrait. Top third: one pinned "grounding" note in the Companion's voice, warm and short. Middle: the corkboard proper, several sticky notes of varying size (size = urgency), the top-priority note wearing the coral pushpin. Bottom: a plain input bar (text/voice toggle) to add a problem or reply.

FORM: Assigned index 3 of the grounded list (sticky-note corkboard), raised by six declined challengers' donations — soft dissolve on completion, plain-spoken labels, continuous unbroken transcript feel, ink-weight-as-intensity, a fixed non-reflowing board frame, urgency-scaled note size with a crisp pin-down entrance. Seed key e13e3cf0.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
