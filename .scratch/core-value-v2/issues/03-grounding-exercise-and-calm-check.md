# Real Grounding Exercise and Calm Check

Status: done

Add a short, skippable Grounding Exercise the Companion offers (breathing and 5-4-3-2-1), and a one-tap Calm Check before and after each Session. Store both per Session locally. Show the user only their own trend; the before/after pairs are the product's success measure.

Acceptance:
- Exercise runs 30–60 seconds, can be skipped at any moment, and makes no clinical claims.
- Calm Check is one tap, never required, recorded before and after the Session.
- A Calm Check value alone never triggers the Safety Net.
- Data is readable for analysis (per Session: before, after, exercise used or skipped).

Blocked by: 01 (Session boundary).
